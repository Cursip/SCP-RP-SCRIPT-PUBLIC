# Security, rights and abuse contact

This repository is **dual-use game-modding content**, published for private use and for reading.
It runs entirely on the client: it talks to no server of ours and collects nothing.

It merges code by **sneakygoober** ("Silent Aim Keyless") and **goatd** ("simple esp (team color)").
Those files were served from the mirror `sneekysscripts.uk`, which is not their author. Credit and
ownership of that code stay with its authors.

If you believe something here infringes your rights, or you want to report abuse of this code,
please **open an issue in this repository first**. That reaches the maintainer directly and is
usually resolved faster than an abuse report. Rights holders, game staff and the authors of the
merged-in code are all welcome to do so.

There is no bug bounty here and no security-sensitive surface of ours to report.
